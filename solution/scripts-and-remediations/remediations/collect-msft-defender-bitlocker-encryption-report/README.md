# Microsoft Intune remediation: Collect Microsoft Defender BitLocker encryption report

Collect Microsoft Defender BitLocker status for all volumes and upload encryption state to Log Analytics in Azure Monitor. The script collects volume encryption details including encryption method, protection status, volume status, and key protector information.

## Script package information

External logging: **Yes**
